Immersive Theater Tokyo — clue photos
=====================================

Drop your real photos here to replace the drawn placeholders. The game
tears each photo into vertical pieces (one per guard on that level) and the
player tapes them back together at the door to reveal the answer.

Required filenames (any of these extensions: .jpg .jpeg .png .webp):

  lantern.jpg   -> Level 1 answer: LANTERN   (torn into 2 pieces)
  mask.jpg      -> Level 2 answer: MASK      (torn into 4 pieces)
  key.jpg       -> Level 3 answer: KEY       (torn into 3 pieces)

Guidelines:
  - Wide / landscape works best (roughly 4:1 to 5:1), since the image is
    shown in a wide box and split into vertical strips.
  - 600–1600 px wide is plenty; it will be scaled to fit.
  - Clear subject on a simple background reads best when torn.

If a file is missing, that level automatically uses a drawn placeholder
image, so the game always works.
